# Fonts for the equiparacion PDF

The PDF embeds metric-compatible open fonts to reproduce the requested document styles on every server:

- Caladea Regular/Bold: Cambria-compatible; Copyright (c) 2012 Huerta Tipografia. Apache License 2.0.
- Carlito Regular/Bold: Calibri-compatible; Copyright (c) 2010-2013 tyPoland Lukasz Dziedzic. SIL Open Font License 1.1. Reserved Font Name "Carlito".
- Liberation Serif Regular/Bold: Times New Roman-compatible; Copyright (c) 2010 Google Corporation and (c) 2012 Red Hat, Inc. SIL Open Font License 1.1.

The corresponding license texts are in LICENSE-Apache-2.0.txt and LICENSE-OFL-1.1.txt.
